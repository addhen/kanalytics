# Dokka Documentation Module

This module is a **documentation aggregator** that generates unified API documentation for the entire KAnalytics library using [Dokka](https://kotlin.github.io/dokka/1.9.20/).

## Purpose

The `dokka` module serves as a centralized documentation hub that:

- **Aggregates** all library modules into a single, comprehensive documentation site
- **Combines** documentation from multiple modules:
  - `kanalytics` - Core analytics library
  - `kanalytics-viewer` - Analytics viewer with UI components
  - `kanalytics-viewer-no-op` - No-operation stub implementations
- **Generates** HTML documentation accessible via web browser
- **Unifies** the documentation experience for developers using the library

---

> **Note**: This module contains no source code - it exists solely for documentation aggregation purposes.
